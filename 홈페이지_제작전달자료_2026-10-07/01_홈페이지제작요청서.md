# 홈페이지 제작 요청서

작성일: 2026-10-07

## 목표와 범위

회사 홈페이지에 자사 제품 소개와 제품별 설명서 다운로드를 넣습니다. 현재 공개 자료실은 파일 다운로드 주소로 계속 사용합니다. 이 묶음은 제품 영역을 만드는 데 필요한 자료입니다. 회사 소개·로고·문의 연락처 등은 별도 제공이 필요합니다.

## 권장 메뉴

- 제품 소개: 제품군별 목록과 제품 상세 페이지
- 자료실: 제품별 설명서·도면 다운로드, 지원 종료 제품 자료
- 문의: 발주자가 제공하는 연락처·문의 채널 연결

제품 목록은 대표 이미지, 제품명, 제품군, 한 줄 설명, 상세 보기 버튼으로 구성합니다. 상세 페이지는 대표 이미지 → 제품 소개 → 주요 특징 → 사양표 → 단자·배선 안내 → 설명서·도면 다운로드 순서를 권장합니다. 휴대폰에서도 이미지와 표를 읽을 수 있게 구성해 주세요.

## 자료 적용 방법

1. `제품목록.csv`로 제품명·분류·소개 초안을 확인합니다.
2. `02_제품콘텐츠`의 제품별 Markdown을 문구와 사양표에 활용합니다. JSON에는 단자·회로·조작 정보도 포함됩니다.
3. 제품 이미지는 `03_웹게시용자료/downloads/<제품슬러그>/product-front.png`를 기본으로 사용합니다. 뒷면은 `product-back.png`, 선화는 `product-line.png`입니다.
4. `03_웹게시용자료/products.html`은 기존 제품 목록의 참고 화면입니다. 홈페이지 공통 디자인에 맞춰 목록과 상세 페이지를 구성해 주세요.
5. 설명서 다운로드 버튼은 `전체다운로드링크.csv`의 공개 URL로 연결합니다. 이미지의 홈페이지 복사·호스팅 여부는 제작 환경에 맞게 정하되 다운로드 파일 주소는 기존 링크를 사용합니다.
6. `90_내부검토_게시금지`의 확인 사항을 담당자와 검토하고 승인된 문구·사양으로 게시합니다.

## 제품 처리 지침

- 11개 GO 제품: 소개·설명서 초안이 준비되어 있습니다. 제공 자료만으로 판매 중·판매 확정 여부를 추정하지 마세요.
- GO-RP2350-CB04T04: 제품 설명서 외에 기존 PCB 도면, 회로도, 모터 온도 측정·릴레이 장치 매뉴얼 v2.7도 함께 제공합니다. 모터 매뉴얼은 제품 자체 설명서와 별도 다운로드로 표시하세요.
- GO-DIRECT-CB3: 원본 폴더 이름은 GO-DIRECT-STAGE3입니다. 화면 제품명은 GO-DIRECT-CB3로 제공되어 있으므로 이름 대응을 유지하고 최종 제품명은 담당자에게 확인해 주세요.
- PI-IO8R: 기존 설명서·회로도만 있습니다. 제품 상태와 정식 소개 내용을 확인한 뒤 목록에 넣습니다.
- ZPI-IO8R: 지원 종료(deprecated). 현재 제품 소개에서 제외하고 자료실의 지원 종료 제품 영역에 보관합니다. 기존 다운로드 URL은 유지합니다.

## 게시 전 확인

PCB 이미지는 실물 사진이 아니라 설계 데이터 기반 렌더링입니다. 원본 사양과 설명서에는 임시로 채운 값이 포함되어 있어 전체 제품 콘텐츠는 검토용 초안으로 전달합니다. 온도·습도, 접점 정격, 센서 범위, 통신 방식 등은 제품별 체크리스트를 확인하세요. 내부 검토 폴더와 내부 검토 내용을 홈페이지에 게시하지 마세요.

## 추가로 받을 자료

회사 로고 원본, 회사 소개, 홈페이지 도메인·제작 환경, 문의 연락처, 제품별 판매 상태·가격 공개 여부·구매 링크, 실물 사진이 있다면 제공받아 적용합니다. 이 묶음에는 해당 정보가 없어 임의로 만들지 않았습니다.
