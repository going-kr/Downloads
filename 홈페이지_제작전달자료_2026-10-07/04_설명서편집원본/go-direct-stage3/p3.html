출력 회로 구성
출력 방식릴레이 접점 (1a)
Common 방식채널별 공통 COM
접점 정격5A 250VAC / 5A 30VDC
구동드라이버 IC (역기전력 클램프 내장)
제어 논리Low 출력 → ON
초기 상태전원 투입 시 OFF
※ 해당 방향 리밋 입력이 OFF 이면 출력 명령과 관계없이 릴레이가 꺼집니다.
리밋 입력 회로 구성
입력 방식포토커플러 절연
입력 신호무전압 접점
입력 점수6점 (UP · DOWN × 3)
공통 단자COM1~3 (내부 공통)
입력 저항4.7kΩ
논리입력 ON → HIGH
※ 리밋 스위치는 LIMIT 단자와 COM 단자 사이에 연결하고, COM 은 0V(GND)에 연결합니다.
OCR 입력 회로 구성
입력 방식포토커플러 절연
입력 신호무전압 접점
입력 점수3점 (CH1~CH3)
동작 조건OCR ↔ GND 단락 시 ON
입력 저항4.7kΩ
논리입력 ON → HIGH
※ OCR 입력은 릴레이 동작과 연동되지 않고 상태만 읽습니다.
I2C 통신 · 주소 설정
연결 버스메인 보드 기계장치 버스
확장 ICMCP23017 (16비트 I/O)
주소 설정Board Number 0~7 → 0x20~0x27
레벨 변환MOSFET 3.3V ↔ 5V
보호10Ω 직렬 · TVS 다이오드
리셋버스 RST 로 확장 IC 리셋
※ 같은 버스에 여러 장을 연결할 때는 Board Number 가 겹치지 않게 설정합니다.
