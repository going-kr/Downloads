주요 특징
GO-DIRECT 스위치 확장 보드 — 스위치 입력 20점 · 출력 20점 · 5채널 커넥터
메인 보드(GO-DIRECT-MAIN) RD장치 버스에 연결하는 I2C 확장 보드
PCA9506(40비트 I/O 확장) 1개로 입력 20점 · 출력 20점
채널 커넥터 5개(SW-CH1~5) — 채널마다 +5V · 입력 4 · 출력 4
입력: 커넥터 +5V 를 스위치로 넣으면 ON (풀다운 · 필터 내장)
출력: 560Ω 직렬 저항 내장, 핀당 소스 10mA · 싱크 25mA
Board Number 로터리로 주소 설정, 5핀 버스 커넥터 2개(병렬)

입력 회로 구성
입력 점수20점 (5채널 × 4)
절연없음 (비절연)
직렬 저항560Ω
풀다운 · 필터4.7kΩ · 0.1µF
동작 조건+5V ↔ SW 연결 시 ON
논리ON → HIGH
※ 스위치는 같은 채널 커넥터의 +5V 와 SW 단자 사이에 연결합니다.
출력 회로 구성
출력 점수20점 (5채널 × 4)
출력 방식확장 IC I/O 직결 · 560Ω 직렬
출력 전류핀당 소스 10mA · 싱크 25mA (5V)
부하 연결LED 램프 (OUT → LED → 0V)
※ 채널 커넥터에는 GND 핀이 없고 +5V 핀만 있습니다.
I2C 통신 · 주소 설정
연결 버스메인 보드 RD장치 버스
확장 ICPCA9506 (40비트 I/O)
주소 설정Board Number 0~7 → 0x20~0x27
레벨 변환MOSFET 3.3V ↔ 5V
보호10Ω 직렬 · TVS 다이오드
리셋버스 RST 로 확장 IC 리셋
※ 같은 버스에 여러 장을 연결할 때는 Board Number 가 겹치지 않게 설정합니다.
