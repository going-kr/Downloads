## 제품 한 줄 소개

RP2040 기반 확장(SUB) 보드 — 아날로그 전압 출력 4채널 · 출력 전원 12~24V · CAN 통신

## 주요 특징 (검토용 초안)

- 메인보드(GO-Pi-Zero-Main)에 이어 꽂는 CAN 확장 보드
- 아날로그 전압 출력 4채널 — PWM → 필터 → LM358 버퍼
- 출력용 전원 DC 12~24V 외부 공급 (12-24V 단자)
- 직류 설정 전압 출력용 (펄스·진동 신호에는 맞지 않음)
- ADDRESS 로터리 스위치로 보드 ID 설정, 확장 보드 여러 장 연결
- RP2040 MCU + 16MB 플래시, USB 로 펌웨어 다운로드
