## 제품 한 줄 소개

PCF8574 I2C 센서 입력 확장 보드 — 절연 입력 8점 · NPN/PNP 선택 · 주소 설정 스위치

## 주요 특징 (검토용 초안)

- 센서 입력 8점, 포토커플러 절연 · 입력마다 표시 LED
- 3선식 센서용 3핀 커넥터 8개 (+ · S · −), 센서 전원 별도 입력
- NPN / PNP 센서 선택 점퍼 (입력 공통 COM 전환)
- PCF8574 I2C 입력 · 인터럽트, 주소 0x20~0x27 스위치 설정
- 확장 커넥터 수·암 1쌍 — GO-RP2040-CB08 J9 와 같은 핀 배열
- I2C · INT 신호 MOSFET 레벨 변환 + TVS 보호
