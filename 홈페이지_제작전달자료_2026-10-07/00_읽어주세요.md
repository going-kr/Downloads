# 홈페이지 제작 전달 자료

2026-10-07 기준. 11개 GO 제품의 소개 초안과 기존 PI-IO8R·지원 종료 ZPI-IO8R 자료를 담았습니다. 다운로드 자료는 총 88개입니다.

## 시작 방법

1. `01_홈페이지제작요청서.md`를 읽어 제작 범위와 제품 처리 지침을 확인하세요.
2. `03_웹게시용자료/products.html`을 더블클릭하면 제품 목록을 인터넷 없이 볼 수 있습니다.
3. `03_웹게시용자료/index.html`에서 기존 RP2350·PI·ZPI 자료도 확인할 수 있습니다.
4. `제품목록.csv`와 `02_제품콘텐츠`에서 제품별 문구·사양 초안을 가져가세요.
5. `전체다운로드링크.csv`에는 이번 자료와 이전 업로드 자료의 공개 URL이 모두 들어 있습니다.

## 폴더 안내

- `02_제품콘텐츠`: 제품별 Markdown·JSON, 통합 products.json
- `03_웹게시용자료`: 오프라인 참고 HTML, 설명서 PDF·이미지·기존 도면
- `04_설명서편집원본`: 설명서 쪽별 HTML과 해당 HTML의 보조 이미지
- `90_내부검토_게시금지`: 임시 사양·확인 항목. 홈페이지에 올리지 마세요.
- `파일검증목록.csv`: 전달 파일 크기와 SHA-256 해시

## 사용 시 확인

제품 콘텐츠는 검토용 초안입니다. 원본에 임시·미확인 사양이 있어 내부 체크리스트 검토 후 게시해 주세요. ZPI는 지원 종료 제품입니다. PI의 현재 제품 상태는 확인이 필요합니다. 이미지가 실물 사진이 아닌 설계 렌더링이라는 점도 구분해 주세요.

공개 자료실: https://going-kr.github.io/Downloads/

ZIP 전체를 웹 서버에 올리지 말고 필요한 페이지·이미지·설명서만 사용하세요. 내부 검토 자료는 제작 검토 용도로만 제공됩니다.
